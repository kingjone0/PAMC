# PAMC

PAMC is an experimental implementation for personalized decentralized federated learning with reinforcement-learning based neighbor selection and metric-weighted aggregation.

This directory is extracted from the original DBAC7 experiment code and renamed for public release. It contains the training entry point, algorithm implementation, model definitions, dataset partition utilities, and runtime helpers required by the main experiments.

## Repository Layout

- `main.py`: main training entry point.
- `pamc/algorithm`: PAMC trainer, client logic, PPO policy, and model trainer.
- `pamc/models`: CNN, LeNet, VGG, and ResNet model definitions.
- `pamc/data/dataprocess`: CIFAR-10, CIFAR-100, MNIST, and EMNIST loaders and partition utilities.
- `pamc/utils`: attack simulation, FLOPs counters, and soft-logits visualization helpers.

## Installation

Create a Python environment and install dependencies:

```bash
pip install -r requirements.txt
```

The code expects PyTorch and torchvision versions compatible with your CUDA or CPU environment. If needed, install PyTorch from the official wheel index first, then run the requirements command.

## Quick Start

Run a small CIFAR-10 experiment:

```bash
python main.py \
  --dataset cifar10 \
  --model cnn_cifar10 \
  --data_dir data \
  --partition_method noniid \
  --partition_alpha 0.1 \
  --client_num_in_total 10 \
  --frac 0.2 \
  --comm_round 20 \
  --epochs 1 \
  --use_rl true
```

Torchvision downloads raw datasets under `--data_dir` when they are not present. Partition files are loaded from paths such as `data/cifar10/cn10_alpha_0.1.json` when provided; otherwise they can be generated by the data loader.

## Outputs

Training logs are written to `LOG/<dataset>/`. Soft-logits plots are written to `slogits_plots_round_<round>/`. These generated artifacts are ignored by git.

## Notes For Public Release

This repository does not include downloaded datasets, generated partition JSON files, logs, checkpoints, or result CSV files. Add only small reproducibility assets that are suitable for public distribution.
